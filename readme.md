### markdown

Alles was man braucht um Text und Webseiten zu schreiben. (Die Darstellung *muss* der Client übernehmen, der Autor kann ja nicht wissen, ob der *Leser* blind ist oder wie gross sein Screen sein könnte.) Da markdown einfach ist, skaliert und textbasier ist, eignet es sich wunderbar um mit **git** versionisiert zu werden und dann wird es auf **github** gehostet. Wie dieses README.md 😳

- Natürlich kann .md in PDF html oder **alles** mögliche umgewandelt werden, wie z.B Javascript oder CLAUDE Features. Für ganz ungemütliche Zeitgenossen gibt es auch MS-WORD oder Apple-Pages translater, was wir hier sicher nicht vertiefen.
